LinkedIn Job Mailer

Save the model and mailbox you want to use. The extension reads the LinkedIn tab you already signed in to. It does not ask for your LinkedIn password.

Mailbox

These settings stay in this browser. Save them before you test the connection. Sending uses a mail program on this computer, because a browser cannot open an SMTP port.

The relay token can stay as the same token. The mail program on this computer no longer checks it.

Matching and signature

Leave this blank to sign the draft with the from name.

Start the mail relay

In a terminal, from the mail-relay folder:

npm install

RELAY_TOKEN="the same token" node server.js

Keep that terminal open while you send. This project folder is inside macOS Public, so leave the API key and SMTP password in the extension only.
